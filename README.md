# Convert_OBJ_to_VTN

ВНИМАНИЕ: Код написан в 2022 г. сразу после окончания срочной службы. Возможны баги

Простая консольная программа конвертации 3D файла формата .obj в файл .vtn (vertex, textures, normals)
Формат не имеет смысла сам по себе, создан для ускорения загрузки данных с SSD на GPU, поскольку не требует подготовки.
Формат представляет из себя голый список вершин, без массива индексов.
